# Project workflow

Start with [monorepo development](skills/mnhospital-monorepo-development/SKILL.md) for every repository change. For a React Native feature, also read [mobile feature development](skills/mnhospital-mobile-feature/SKILL.md). For a GraphQL, login, booking, payment, medical, or staff flow, also read [API contract review](skills/mnhospital-api-contract/SKILL.md).

These guides select a workflow, not a license to copy browser code into native. Existing product behavior and visual decisions live in `docs/`; `docs/ai/` holds cross-platform decisions, evidence, and the next task. The nearest `AGENTS.md` sets directory-specific rules.

Follow the ordered [delivery roadmap](docs/ai/ROADMAP.md) and [privacy boundaries](docs/ai/PRIVACY.md) before adding new data flows.
